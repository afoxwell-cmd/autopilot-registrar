How the flow works
  1. On the laptop, run Get-WindowsAutopilotInfo -OutputFile C:\hash.csv and paste the hardware hash above (for new devices).
  2. Click "Create session & show QR" — this uploads the device data to your backend and gets a short session ID.
  3. The client scans the QR with their phone; the backend calls Microsoft Graph to import/assign the device to the user.
  4. If the preview here blocks the network upload, use "QR with inline params" instead (works for devices already registered in Autopilot).
